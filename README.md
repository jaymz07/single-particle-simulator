# single-particle-simulator
Fast simulation of a single particle under the action of an arbitrary position dependent force field. There was much emphasis on comparison of symplectic algorithms when writing the code.

Some theory of symplectic algorithms can be found in the document:
[📄 SIMULATION THEORY.pdf](https://raw.githubusercontent.com/jaymz07/single-particle-simulator/main/SIMULATION%20THEORY.pdf)

Some interesting and pretty results can be found in the document:
[📄 ORBIT FRACTALS.pdf](https://raw.githubusercontent.com/jaymz07/single-particle-simulator/main/ORBIT%20FRACTALS.pdf)
